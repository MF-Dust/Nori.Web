# Maintainable frontend source

This directory is the clean-room source workspace for the local Nori.Web frontend.

The current production UI in `public/assets/` is a set of hashed Vite chunks. Recovery tooling can make those chunks readable and extract structure, but it cannot recreate the exact original TypeScript/TSX project because no source maps are shipped.

Code added here should therefore be written from verified protocol behavior and observed UI behavior, with stable names and tests. It should not be generated by copying formatted production bundles into the repository.

Initial source modules live under `runtime/`. As more of the UI is reimplemented, the intended shape is:

```text
frontend-src/
├── runtime/       # Arcade protocol, transport, auth and shared stores
├── components/    # reusable UI pieces
├── apps/          # Mail, Files, Browser, Messenger, Terminal
├── cartridges/    # Chat and game UIs
└── shell/         # desktop shell, settings and Live2D stage
```

The migration is incremental: a reconstructed module should gain tests and then replace only its corresponding hashed chunk/compatibility shim.
