# Frontend application and screen coverage matrix

This matrix covers every application in `NORI_PRODUCTION_APPS`. The status in parentheses is the registry descriptor, not a parity verdict. “Source gap” records a concrete capability still absent from the maintained implementation. “Acceptance pending” records implemented behavior that still needs CI, reference-client, private-agent or broader corpus verification. A blank source gap does not mark a cutover boundary complete.
