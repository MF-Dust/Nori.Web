# Frontend application and screen coverage matrix

This matrix tracks every application registered by `NORI_PRODUCTION_APPS`. The catalog status is the current descriptor value, not a claim that original behavior or visual parity is complete. A window is usable only when the source session also supplies its binding; `createProductionWindowAppDefinition` deliberately leaves an unbound surface without an implementation.
